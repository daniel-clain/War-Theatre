## 🧠 Core Psychological Mechanisms of Mystery Engagement

These are **cognitive and motivational engines** that drive a person to resolve mysteries. Each one corresponds to a known psychological principle and explains _why_ we feel compelled to investigate.

| Principle                                      | Description                                                                                                                                                                 |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Cognitive Dissonance Resolution**            | When two beliefs or observations contradict, the mind _must_ resolve the inconsistency to return to internal harmony. Mysteries deliberately provoke this discomfort.       |
| **Prediction Error / Schema Violation**        | The brain constantly predicts reality based on learned patterns. When a prediction fails, a spike of neural surprise (dopamine + attention) forces the brain to re-analyze. |
| **Information Gap Curiosity (Loewenstein)**    | Awareness of a knowledge gap generates tension. The closer the answer seems, the more intense the craving to find it.                                                       |
| **Need for Cognitive Closure**                 | Humans dislike ambiguity. When a question is open, they’ll accept even imperfect answers to relieve uncertainty.                                                            |
| **Zeigarnik Effect**                           | Unfinished mental tasks remain more accessible and intrusive than completed ones—fueling fixation.                                                                          |
| **Effort Justification**                       | The more effort spent, the more value is placed on reaching a conclusion—amplifying obsession once invested.                                                                |
| **Mastery Drive (Competence Motivation)**      | Solving mysteries validates intelligence and skill. Players are driven by a need to demonstrate cognitive mastery.                                                          |
| **Moral Salience (Ethical Injustice Trigger)** | If the mystery involves wrongdoing or betrayal, players feel a personal moral need to expose the truth.                                                                     |
| **Suspicion Bias**                             | When something _might_ be off, even without evidence, the brain over-allocates attention to protect from threats (evolutionary vigilance system).                           |

## 🧩 High-Impact Mystery Triggers

These are **designable elements** you can place in the story or world that reliably provoke the psychological mechanisms above. They’re grouped by what kind of tension they create.

### 🔻 Contradiction Triggers (Activate Cognitive Dissonance + Curiosity)

| Name                       | Description                                                                                      |
| -------------------------- | ------------------------------------------------------------------------------------------------ |
| **Logical Contradiction**  | Two facts can’t be simultaneously true (e.g. someone has an alibi _and_ is seen at the scene).   |
| **Testimony Conflict**     | Eyewitnesses or documents disagree in a provable way.                                            |
| **Cause-Effect Mismatch**  | An outcome doesn’t follow its supposed cause (e.g. suicide method doesn’t match physical signs). |
| **Behavioral Incongruity** | A person’s actions contradict their known traits or values.                                      |

### 🧩 Incompletion Triggers (Exploit Zeigarnik, Curiosity, Closure Needs)

| Name                      | Description                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------------- |
| **Interrupted Narrative** | A story, file, or conversation ends abruptly.                                                     |
| **Vanished Evidence**     | Something mentioned earlier is now gone (e.g. the note was here yesterday).                       |
| **Unfinished Ritual**     | An action appears to be started but never finished (e.g. half-eaten food, unclicked send button). |
| **Postponed Revelation**  | A character implies knowledge, then delays or dies before revealing it.                           |

### 🧩 Pattern Disruption Triggers (Exploit Prediction Error + Suspicion Bias)

| Name                         | Description                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------------- |
| **Off-by-One Pattern**       | Something mostly fits a known pattern, but not quite—e.g. one day missing from a daily log. |
| **Anomalous Placement**      | An object appears in a setting it symbolically or functionally doesn’t belong.              |
| **Too Perfect / Too Clean**  | Someone or something appears overly polished or helpful, triggering distrust.               |
| **Reversal of Expectations** | A villain seems noble, or a hero turns suspicious. Disrupts schema alignment.               |

### 🧩 Moral Tension Triggers (Exploit Injustice Motivation)

| Name                    | Description                                                                  |
| ----------------------- | ---------------------------------------------------------------------------- |
| **Unpunished Crime**    | A wrong was clearly committed, and no one seems to care.                     |
| **Moral Masking**       | A person doing good seems to be covering something dark.                     |
| **Victim Complexity**   | A victim is not who they seem—e.g. a missing child was the actual aggressor. |
| **Authority Deception** | Trusted institutions or figures are caught concealing truth.                 |

## 🧠 Emotional-Experiential States of the Obsessed Player

These are **outcomes** of the psychological triggers above—feelings that make the mystery linger in the player’s mind even when they’re not playing.

| State                    | Description                                                                            |
| ------------------------ | -------------------------------------------------------------------------------------- |
| **Cognitive Itch**       | An unresolved thought loop that keeps resurfacing until satisfied.                     |
| **Tension with Self**    | Internal argument—“I _think_ I know, but what if I’m wrong?”                           |
| **Restless Simulation**  | The player keeps mentally replaying the scene, testing alternate explanations.         |
| **Righteous Motivation** | They want to solve it not just out of curiosity—but because _someone needs to_.        |
| **Suspicion Overdrive**  | Once doubt is seeded, the player can’t trust anything they see.                        |
| **Narrative Possession** | The mystery world bleeds into real life—they think about it in the shower or on walks. |
| **Closure Urgency**      | A strong drive to finish the story or resolve the question before moving on.           |
| **Emotional Echo**       | Lingering dread, awe, sadness, or fascination after a disturbing reveal.               |
| **Isolation of Insight** | A player feels they’ve seen a truth no one else has—and must now carry it alone.       |
